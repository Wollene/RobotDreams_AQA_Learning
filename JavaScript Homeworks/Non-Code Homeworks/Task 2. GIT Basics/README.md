
# Task 2. GIT Basics

> Learn version control fundamentals by completing an interactive Git course and setting up a GitHub workflow.

## Overview

This task introduces Git and GitHub as the core tools for version control and collaboration. The goal is to understand branching, committing, and opening pull requests — skills used in every future task.

---

## Steps

1. Complete the interactive Git course at [learngitbranching.js.org](https://learngitbranching.js.org/?locale=uk)
2. Create a GitHub account
3. Create a new repository with at least one commit
4. *(Bonus)* Open a pull request and add [vlevkoniuk](https://github.com/vlevkoniuk/vlevkoniuk) as a reviewer

---

## Deliverable

Screenshots of the pull request with the reviewer attached.

---

## Key Concepts

- **Repository** — a tracked project folder that stores the full history of changes
- **Commit** — a saved snapshot of changes with a descriptive message
- **Branch** — an isolated line of development that can be merged back into the main branch
- **Pull Request (PR)** — a request to merge changes from one branch into another, often used for code review
