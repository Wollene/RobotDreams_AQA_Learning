
# Task 1. Introduction to AQA and Setting Up

> Set up a local development environment for JavaScript and TypeScript automation testing.

## Overview

This task covers the initial setup required before writing any automated tests. The goal is to install and verify all the necessary tools, ensuring a working development environment for the rest of the course.

---

## Requirements

Install and configure the following tools:

| Tool | Purpose |
|------|---------|
| [Node.js](https://nodejs.org/) (LTS) | JavaScript runtime for running scripts and test frameworks |
| [npm](https://www.npmjs.com/) (latest) | Package manager for installing dependencies |
| [VSCode](https://code.visualstudio.com/) | Code editor used throughout the course |
| VSCode Extensions | Syntax highlighting, linting, and productivity tools |

---

## Deliverable

A terminal screenshot and a VSCode screenshot showing that all tools are installed and working correctly.

---

## Key Concepts

- **Node.js** — a JavaScript runtime built on Chrome's V8 engine, required for running JS outside the browser
- **npm** — Node Package Manager, used to install and manage third-party libraries
- **LTS** — Long-Term Support; the stable Node.js release recommended for production and learning environments
